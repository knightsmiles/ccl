Keep track of who owes whom, without money or the Internet.

Community Credit Ledger is free software for a community that trades skills and goods among its members. It runs on one ordinary computer with no network connection. Each member carries a USB stick, and every trade is signed by both people.

What it's for

It's for villages, farms, intentional communities, and neighborhoods that want to trade fairly without cash, cards, or a bank in the middle. An electrician, a farmer, a mechanic, and a cook can trade with each other, even when nobody has what the other wants right now.

Each member sets their own rate, and both sides agree on every trade. A shared directory lists what members offer and what they need. If you have a used car to trade and need a roof fixed, you can find someone who wants the car.

How a trade works

  1. Two members agree on the work or goods and on how many credits it's worth.
  2. Both go to the community computer, plug in their USB sticks, and type their PINs.
  3. The trade is signed by both members and added to the ledger. It can never be changed or quietly erased afterwards.
  4. Each member's stick gets a signed receipt to keep.

What you need

  • One computer running Linux to hold the ledger. It doesn't need an Internet connection.
  • One USB stick per member. A YubiKey-type security key can be used instead.
  • Someone willing to act as the administrator, who enrolls members and keeps backups.

It works for a handful of members or for thousands.

Why people can trust the ledger

No single person, not even the administrator, can add, change, or delete a trade. Every entry needs both members' signatures, and each entry is chained to the one before it. Any member can run a check that confirms the whole ledger is intact. The cryptography is standard and widely used, with no home-made methods.

Current status

Version 0.1.0, first release. It works and has a full test suite. Hardware security keys have not yet been tested on real devices, and linking separate communities' ledgers is planned but not built. The code hasn't had an independent security review.

ccl is offered as is, with no support. The author doesn't answer questions or take requests. Everything needed to set it up is in the manual. Anyone is free to fork it, improve it, and maintain their own version.

Get it

Get it on GitHub Read the manual Download 0.1.0

On Ubuntu or Raspberry Pi OS, with the computer briefly connected to the Internet:

sudo apt install python3-pip
pip install --break-system-packages https://github.com/knightsmiles/ccl/archive/refs/tags/v0.1.0.tar.gz

After that the computer can stay offline for good. The manual walks through every step from there, written for someone who has never used Linux.
